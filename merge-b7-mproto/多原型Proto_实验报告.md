## 1. 实验设置

| 项目 | 内容 |
|---|---|
| 数据 | MM-SafetyBench SD_TYPO，1680 条，13 类合并为 7 类 |
| 特征 | Qwen3-VL-8B-Instruct，4096 维，`center-abtt1`（去均值 + 去掉第一主方向） |
| 预处理拟合 | 均值和主方向用全部 1680 条估计（含未知类），沿用旧实验口径 |
| 层 | decoder 24、32 |
| 未知类 | 每 seed 随机抽 2 个合并类，`--n-unknown 2` |
| 切分 | 按 `question` 分组；已知类 90% 训练/验证、10% 测试，训练部分再切 10% 验证 |
| seed | 42–46（未知类组合与切分和旧报告一致） |
| 方法 | 单原型 proto、多原型 K=1–4；CAC 复用旧结果 |
| 多原型聚合 | 训练 `logsumexp_k(s/tau)`，打分 `max_{c,k} s` |
| 原型初始化 | `randn * 0.1`，不加多样性正则 |
| 超参数 | dim=256, tau=0.1, lr=1e-3, batch=64, weight_decay=1e-4, epochs=200, patience=50 |
| 阈值 | 验证集已知分数 95% 分位；测试集不参与 |
| 设备 | gpu0（旧 CAC 也是 gpu0） |
| 汇报口径 | 仅 B_matched（未知类下采样到与已知测试集 1:1） |

**多原型定义**：`z = normalize(Wx)`，`P ∈ R^{C×K×d}` 每个原型 L2 归一化；
`s[c,k] = z·P[c,k]`，训练 logits 为 `l[c] = logsumexp_k(s[c,k]/tau)`，损失为交叉熵；
已知度分数 `max_{c,k} s[c,k]`，预测类 `argmax_c max_k s[c,k]`。K=1 时与单原型 Proto 等价。

## 7. 注意事项

- **ABTT 口径**：均值和第一主方向用全部 1680 条（含未知类）估计，属于无标签的宽松口径；
  沿用旧实验是为了可比，不代表更严格的已知类拟合。
- **类别不均衡**：合并后 M5=465、M1=443，而 M6/M7=109；固定 K 对不同类的相对容量不同，
  拒绝率的标准差可能较大。
- **验证集双重用途**：验证集同时用于早停和阈值标定；K 固定为 3，K=1–4 只作敏感性，
  没有按测试集挑选 K。
- **单次初始化**：每个切分只训练一个模型初始化（seed 同时控制切分与初始化），
  没有单独估计训练方差。
- **口径**：只报 B_matched；未知类全量的 A_full 未计算。CAC 是旧结果，未在新目录重跑。
- **K=1 校验**：若第 4 节 max|Δ| 超过 1e-4，应先排查实现，而不是解读多原型结果。
