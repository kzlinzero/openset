# merge-b7 · 去均值 / all-but-the-top（可选开关）+ 对比实验

## 一、目标与范围

在 **merge-b7 的合并 7 类特征**上，把「去均值 / all-but-the-top」做成**可选预处理**，跑「基线 vs 去均值 vs 去均值+ABTT」的对比实验并出报告。**不动 `openset-proto/proto_openset.py`**，沿用 merge-b7 已有的「数据层预处理 + 驱动调用」模式。

已确认的参数：拟合范围 = **全部 1680 条（全局、无标签）**；变体 = **去均值 + ABTT(k=1)**；方法 = **cac + arpl**；层 = L24/L32；seed = 42–46。

## 二、预处理定义（精确）

对每一层的合并特征矩阵 `X`（N×4096）：

1. **去均值（mean）**：`μ = X.mean(axis=0)`；`Xc = X − μ`
2. **ABTT(k=1)**：在 `Xc` 上做 PCA/SVD，取**第一主方向** `v₁`；`X' = Xc − (Xc·v₁) v₁`
3. `X'` 以 float32 写回一个新 npz，其余字段（category/question/index/…）**原样保留**

下游流程不变：`proto_openset.py` 拿到 `X'` 后，先做（默认关闭的）PCA，再**逐行 L2 归一化**，然后训练。所以「去均值 + L2 归一化」得到的就是标准的 centered-cosine 表示。

**方法学说明（要写进报告）**：均值/主方向用**全部 1680 条**估计，其中包含某些 seed 里会被划为未知类的样本。这是无标签估计、且对所有类一视同仁，ABTT 文献通常这么做；但它确实"看过"未知样本特征，属于需要声明的口径。

## 五、报告内容（`合并B7_去均值ABTT_实验报告.md`）

1. **本次运行的命令与文件清单**（你特别要求的）：逐条列出每次运行用的 **npz 文件路径、run-name、输出目录、以及等价命令**——直接从每个 run 目录的 `manifest.json`（含 `args` / `npz` / `run_dir`）里读，保证是"实际跑过的"而不是手写。
2. 方法学口径说明（全局拟合、不看类别划分）+ 预处理公式。
3. 每 seed 抽中的未知类组合（与上次一致）。
4. 主表（B_matched）按**变体**分组：raw / mean / abtt1 × 层 × 方法，5 seed 均值±std；A_full 作附表。
5. **核心对比表**：raw → mean → abtt1 的 AUROC / 闭集ACC / 拒绝率 / FPR 变化（Δ 标出），一眼看出去均值与 ABTT 各贡献多少。
6. 误判方向（按未知类聚合，分变体）。
7. 注意事项（口径不同不可严格对比、未知类抽取方差、全局拟合的两面性等）。
