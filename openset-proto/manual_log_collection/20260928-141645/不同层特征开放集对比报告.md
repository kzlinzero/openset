# 不同层特征对开放集识别的影响（Qwen3-VL-8B / MM-SafetyBench）

- 日期：2026-09-28
- 脚本：`openset-proto/proto_openset.py`，参数 `--method all --seed 42 --device gpu0`，其余均为默认值
- 汇报口径：**B_matched**（开放集与闭集测试样本 1:1，已知测试 112 vs 未知 112）
- 汇报指标：AUROC、闭集 ACC、未知拒绝率、FPR@TPR95

## 1. 实验设置

| 项目 | 内容 |
|---|---|
| 底座模型 | Qwen/Qwen3-VL-8B-Instruct（fp16，特征维度 4096） |
| 数据 | MM-SafetyBench SD_TYPO，1680 样本，13 个不安全类别 |
| 特征提取 | `get-embedding/build_embeddings.py`，对 prompt 的 hidden states 取 mean pooling |
| 对比层 | decoder 第 8 / 17 / 24 / 32 层，以及最后一层（`-1`） |
| 已知 / 未知类划分 | seed=42 随机选 4 个未知类：01-Illegal_Activity、02-HateSpeech、05-EconomicHarm、11-Financial_Advice（9 已知类） |
| 数据划分 | group split（同一 question 不跨划分），train 917 / val 102 / 已知测试 112 / 未知 549 |
| 方法 | ncm（最近类均值）、proto（原型网络微调）、cac、arpl |
| 阈值 tau | 各方法在验证集上按 TPR 95% 校准 |

5 个层使用完全相同的未知类划分与数据划分（seed 固定），结果可直接横向对比。本次 layer -1 的结果与 2026-09-21 用旧 npz（`MMSB_sd_typo.npz`，同为最后一层特征）的运行逐项一致，说明流程可复现。

## 3. 分析

### 3.1 层深度：中深层特征显著优于浅层，第 24/32 层最佳

- **浅层（L8）明显不行**：proto 的 AUROC 只有 0.6484，未知拒绝率 4% 左右——浅层特征里未知类样本几乎全部塌缩进已知类原型；ncm 更是低于随机（0.4745）。这说明 L8 特征主要编码表层/词面信息，类间判别结构还没形成。
- **中层（L17）到中深层（L24）快速提升**：proto 从 0.8102 升到 0.8571，cac 从 0.8308 升到 0.8609，闭集 ACC 普遍达到 0.85+。
- **L24 与 L32 基本打平，各有侧重**：L24 在 FPR@TPR95 上最好（arpl 0.5089）且闭集 ACC 最高（cac 0.8929）；L32 在 AUROC（proto 0.8695）和未知拒绝率（cac 0.4911）上最好。
- **最后一层（-1）反而回落**：最明显的是 proto，AUROC 从 L32 的 0.8695 掉到 0.7815；arpl 也从 0.8535 掉到 0.8229。这一现象与"最后一层特征过度任务特化（对齐到 next-token 预测）、类间结构反而不如中深层清晰"的常见观察一致。做开放集识别时应取中深层（约 24~32 层）特征，而不是直接用输出层特征。

### 3.2 方法对比

- **ncm 在所有层都失效**（AUROC 0.47~0.57，FPR@TPR95 > 0.93）：类均值距离这个度量下未知类与已知类无法区分，说明未知类并非简单的"远离所有已知类均值"，需要学习型的打分。
- **学习型方法（proto / cac / arpl）趋势一致**：均在中深层（L24/L32）达到峰值。proto 对特征层最敏感（L8→L32 相差 0.22 AUROC），cac/arpl 对层的选择更鲁棒。
- **cac 在 L32 拒绝率最高（0.4911）但 FPR@TPR95 也偏高（0.6250）**，说明它的分数分布使得 tau 阈值能拒绝更多未知类，但同时把已知类也误拒得更多；综合看 L24 cac（拒绝率 0.2946 + FPR 0.6071 + 闭集 0.8929）更均衡。
- **arpl 在 FPR@TPR95 上整体最强**（L24 0.5089 / L32 0.5625），即"把 95% 已知类接受下来时混入的未知类最少"，如果更看重低误报，arpl + L24/L32 是当前最优组合。

### 3.3 未知类难度（proto 方法的分类别拒绝率）

- L8：四个未知类的拒绝率都只有 5%~9%，几乎全被当成已知类接受。
- L24/L32：01-Illegal_Activity 始终最难拒绝（15%~19%），02-HateSpeech、05-EconomicHarm、11-Financial_Advice 相对容易被识别为未知（22%~38%）。
- 误判方向上（以 layer -1 为例），05-EconomicHarm 和 11-Financial_Advice 大量被归到 06-Fraud / 10-Legal_Opinion，语义相邻的类别（经济有害↔欺诈、金融建议↔法律意见）在特征空间中确实更接近，是后续可针对性改进的点（如更细的类间边界约束）。

### 3.4 局限

- 单 seed（42）单次运行：已知测试集只有 112 个样本，单个指标的最小粒度约 0.9 个百分点，L24 与 L32 之间的很多差距在噪声范围内；如需下结论建议跑 3~5 个 seed 取均值±方差。
- 未知类只有 4 个类别、比例固定 1:1，未覆盖其他未知类组合与比例。
- 闭集 ACC 与开放集指标之间存在 tau 阈值选择的影响，未做阈值敏感性分析。
