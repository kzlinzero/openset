# 不同层特征对开放集识别的影响——5 种子平均（Qwen3-VL-8B / MM-SafetyBench）

- 日期：2026-09-28
- 脚本：`openset-proto/proto_openset.py`，参数 `--method all --device gpu0`，其余均为默认值
- 种子：seed 42 / 43 / 44 / 45 / 46 各跑一次，共 5 层 × 5 种子 = 25 次运行
- 汇报口径：**B_matched**（开放集与闭集测试样本 1:1，已知测试 112 vs 未知 112）
- 汇报指标：AUROC、闭集 ACC、未知拒绝率、FPR@TPR95，表格中为 **均值±标准差**（样本标准差，n=5）

## 1. 实验设置

| 项目 | 内容 |
|---|---|
| 底座模型 | Qwen/Qwen3-VL-8B-Instruct（fp16，特征维度 4096） |
| 数据 | MM-SafetyBench SD_TYPO，1680 样本，13 个不安全类别 |
| 特征提取 | `get-embedding/build_embeddings.py`，对 prompt 的 hidden states 取 mean pooling |

| 种子 | 42–46；seed 同时控制未知类随机选择、数据划分与训练初始化，即每个种子是一次完整的随机重采样 |
| 数据划分 | group split（同一 question 不跨划分），train 917 / val 102 / 已知测试 112 / 未知 549 |
| 方法 | ncm（最近类均值）、proto（原型网络微调）、cac、arpl |
| 阈值 tau | 各方法在各种子下于验证集按 TPR 95% 校准 |

## 4. 分析

### 4.1 层深度：L24~32 仍是最优区间，最后一层回落，L8 明显最差

- **L8 稳定最差**：三种学习型方法的 AUROC 均值（proto 0.6612 / cac 0.7712 / arpl 0.6984）比各自的 L24/L32 峰值低 0.06~0.15，且都超出了各自的标准差范围，是唯一可以明确下"显著更差"结论的层。
- **L24 与 L32 打平**：proto 峰值在 L24（0.8061），cac/arpl 峰值在 L32（0.8574 / 0.8446），但两者差距（0.004~0.03）均远小于标准差（0.03~0.04），统计上不可区分。
- **最后一层（-1）回落趋势保持**：proto 0.7783、arpl 0.7978，比各自峰值低约 0.03~0.05；proto 的回落幅度（约 1 个标准差）勉强超出噪声，arpl 与噪声相当，趋势方向与单 seed 一致但幅度收窄。cac 回落最温和（0.8221，比峰值低 0.035）。
- 综合结论：**应选中深层（约 24~32 层）特征**，这与单 seed 观察一致；不必纠结 L24 还是 L32。

### 4.2 方法对比

- **ncm 在所有层、所有种子下都失效**（AUROC 均值 0.52~0.55，FPR@TPR95 > 0.96），证实未知类不是"远离所有已知类均值"的简单分布外点。
- **cac 综合最强且对层最鲁棒**：AUROC 均值峰值 0.8574（L32），闭集 ACC 峰值 0.8884（L32），未知拒绝率峰值 0.3575（L32），且从 L17 起就已接近峰值（0.8315）。四个指标的最优几乎都落在 L32 行。
- **arpl 的 FPR@TPR95 最低**（L32 均值 0.6393，与 cac 的 0.6402 基本并列），但注意其 FPR 的标准差较大（±0.10~0.11），单次实验中该指标波动明显。
- **proto 对特征层最敏感**（L8→L24 AUROC 相差 0.145），但其峰值 AUROC（0.8061）低于 cac/arpl（0.8574/0.8446）。
- 与单 seed 报告相比的一个修正：单 seed 时 proto 的 AUROC 峰值（0.8695）曾显著领先，多种子平均后 proto 的优势消失——那次是 seed 42 组合（未知类为 Illegal_Activity/HateSpeech/EconomicHarm/Financial_Advice）下的偏乐观结果，说明**proto 的表现在不同未知类组合间波动较大**（其 AUROC std 0.03~0.04 也是三者中最高之一）。

### 4.3 方差来源

- 指标标准差普遍在 0.02~0.07（未知拒绝率、FPR@TPR95 可达 ±0.10~0.16），其中相当一部分来自**未知类组合的差异**（5 个种子的未知类组合完全不同，如 seed 44 的未知类偏"内容安全"类、seed 45 偏"决策/建议"类），而非纯训练噪声。这说明报单次运行的结果时，未知类组合的选择本身就是最大的混淆因素之一。
- 已知测试集仅 112 样本，单个指标最小粒度约 0.9 个百分点，闭集 ACC 的 ±0.02~0.05 波动与此一致。

### 4.4 局限

- 5 个种子对于区分 L24 与 L32 这种小差距仍不够（差距 ≪ 标准差），只能下"打平"的结论；若要严格排序需要更多种子或配对检验。
- 未知类固定为 4 个、比例固定 1:1，未覆盖其他数量与比例。
- 闭集 ACC 与开放集指标受 tau 阈值校准影响，未做阈值敏感性分析。
- 各层共享同一批种子，属于配对设计；如需更严格的层间显著性结论，应做配对 t 检验或 Wilcoxon 检验（当前数据量下仅作参考）。
